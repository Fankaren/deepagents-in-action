- **一句话解释**：`他律笔记：不靠意志力，靠系统——把认知写成能复用的笔记。`
- **延展**：栏目用「·系列名」标注（如 `他律笔记 · 底层逻辑`）。

## 三、头像设计规范

- **规格**：正方形 1:1，导出 **1024×1024**（微信最小 240×240），PNG/JPG，圆形裁切后主体居中。
- **配色**：深墨蓝底（#0C1220~#1C2A44）+ 琥珀金（#FFB13B~#FF7A00），白字点缀。
- **避坑**：不用真实人脸；细节别太碎；不与知名商标雷同；不含二维码/联系方式。

**本轮设计要点**
- **字更大更粗**：主字 font-size 376~392、字重 800，接近满幅；圆相版 246。
- **毛笔飞白 / 墨韵**：主字用墨色渐变 + `feTurbulence`+`feDisplacementMap` 让笔画边缘带笔意；背后叠一层高斯模糊的淡墨晕染；再用「纸色细纹 + 字形遮罩」叠出**飞白**。
- **做旧朱文印**：朱红降至做旧色 `#8E3A2A`，加毛边滤镜（做旧）；**印章缩小**（86~92px），白字「他律」竖排，**字不出框**。
- **榜书/书法字体栈**：`STKaiti / KaiTi / STXingkai / LiSu / Noto Serif SC`（按环境可用者生效；想要更“榜书”可另装书法字体）。

> 提示：若字的飞白/毛边在不同渲染器表现不一（各浏览器对 SVG 滤镜支持略有差异），以 Chrome 预览为准。

**SVG → PNG（微信需位图）三选一**：
1. 浏览器打开 SVG → 截图 1024×1024；
2. ImageMagick：`magick -background none -density 384 avatar-monogram.svg -resize 1024x1024 avatar.png`；
3. 在线转换（svgtopng / cloudconvert）。
