# wechat-article · 男性向微信公众号推文模板

> 本技能是**格式统一器**：无论选题来自哪里，成稿必须遵循下面的固定骨架与文风纪律。
> 目标：**体系化长文**，每篇可独立阅读、又属于某个系列、能沉淀可复用知识。
> （观测标记 WECHAT-SKILL-LOADED —— 只有读过本正文才会出现。）

## 一、固定骨架（缺一不可）

```markdown
# 【他律手记 · <系列名>】第 N 篇 —— <爆款标题>

> 封面建议：<一句话画面描述 + 构图/色调>

## 导语
<2-3 句，先抛冲突/悬念，勾住读者>

## 01 <小节标题>
<观点 + 例子/数据/场景>

## 02 <小节标题>
<递进，制造"原来如此"的获得感>

## 03 <小节标题>
<继续深化：反常识 / 常见误区>

## 04 <小节标题>
<落地：可操作框架 / 清单 / SOP>

## 结尾互动
<一句提问或号召，引导留言/转发>

## 配图位
<每节建议配图 + 图片来源说明>

## 本篇沉淀（供 knowledge-base 复用）
<1 个可复用框架 / 金句 / 案例，标注所属系列>

## 署名
> —— 他律手记（不靠意志力，靠系统）
```

## 二、标题纪律（男性向爆款）

- 15-24 字；用**具体数字 / 身份标签 / 冲突词 / 悬念**（如"30 岁后""底层逻辑""别再"）。
- 给 **3 个候选**标题，标注推荐度（★）。
- 禁止标题党到失真：正文必须兑现标题承诺。

## 三、文风纪律

- 短句、口语、有节奏；每段 2-4 行，手机屏易读。
- 立场鲜明（男性受众爱"观点 + 证据"），但**不碰下三路、不贬损性别群体、不传播未经证实的健康/投资结论**。
- 每节结尾给一句"金句"（可截图传播）。
- **篇幅与深度：全文 1800-2600 字，阅读约 6-9 分钟；至少 4 个小节**；拒绝水文、凑字。
- 全文必须有**一个可复用框架/清单**（这是系列"知识沉淀"的来源）。
- **系列一致性**：同一系列的命名、口吻、结构保持一致；引用前文时点名"第 N 篇"。

## 四、配图纪律

- 每节 1 张，标题区 1 张封面；图片用**免费图床 URL**（由 image-scout 子 Agent 提供）。
- 图注写明来源与用途，避免版权风险。

## 五、产出物

1. 终稿 Markdown（按上面骨架，含系列标识与「本篇沉淀」）；
2. 发布信息：标题、封面图 URL、草稿路径；
3. 选题依据（所属系列 + 为什么这个方向/这个角度容易爆 + 与 performance 数据的呼应）。
