# 品牌方案 · 男性向公众号「他律」

> 面向：25-40 岁男性｜方向：男性成长与效率（职场底层逻辑 / 财富习惯 / 认知升级 / 决策工具）
> 调性：**硬核、务实、有体系、可沉淀**（长文 1800-2600 字 / 6-9 分钟）

## 一、最终定名：**他律**

- **含义**：自律的他者化——把“该做的事”交给规则、清单、契约来约束，而不是靠意志力硬扛。2 字极简、独特、有逼格，直接点题「习惯复利 / 决策工具」两条主线。
- **一句话解释（放简介里）**：`他律：不靠意志力，靠系统。`
- **延展**：名字短，适合做专栏前缀（如「他律·底层逻辑」「他律·决策工具箱」）。

## 二、账号简介（示例）

- 一句话：**「他律：不靠意志力，靠系统——给 25-40 岁男性的认知基建。」**
- 详细版：`只写经得起复盘的硬内容：职场底层逻辑、财富习惯、认知升级、决策工具。用规则与清单替代意志力，把碎片努力变成复利资产。每日一篇体系化长文。`

四个系列即四个专栏（建议加「他律·」前缀）：
1. 他律·底层逻辑（职场/商业第一性原理）
2. 他律·习惯复利（财富与自律的长期工程）
3. 他律·决策工具箱（可操作方法与清单）
4. 他律·认知升级（反常识与思维模型）

> 已落选备选（备查）：硬核进化 / 进化日志 / 成事笔记 / 认知军火库 / 三十而励。

## 三、头像设计规范

- **规格**：正方形 1:1，建议导出 **1024×1024**（微信最小 240×240），PNG/JPG，圆形裁切后主体居中。
- **配色**：深墨蓝底（#0C1220~#1C2A44）+ 琥珀金（#FFB13B~#FF7A00），白字点缀——男性、高级、耐看。
- **避坑**：不用真实人脸；细节别太碎（列表缩略图要可辨）；不与知名商标雷同；不含二维码/联系方式。

3. 在线转换（svgtopng / cloudconvert）。
