# 品牌方案 · 男性向公众号「他律手记」

> 面向：25-40 岁男性｜方向：男性成长与效率（职场底层逻辑 / 财富习惯 / 认知升级 / 决策工具）
> 调性：**硬核、务实、有体系、可沉淀**（长文 1800-2600 字 / 6-9 分钟）
> 沿革：他律（占用）→ 他律笔记 → **定名「他律手记」**（已注册）。头像定稿：`avatar-enso`。

## 一、最终定名：**他律手记**

- **含义**：延续「他律」（不靠意志力、靠系统）+「手记」（持续记录、体系化、知识沉淀）。
- **一句话简介**：`他律手记：不靠意志力，靠系统——给 25-40 岁男性的认知基建。`
- **栏目**：`他律手记 · 底层逻辑 / 习惯复利 / 决策工具箱 / 认知升级`
- **署名**：成稿标题用「他律手记 · 系列」标注，文末署名「—— 他律手记（不靠意志力，靠系统）」。
- 备选（备查）：他驱 / 铁律 / 刻度 / 戒尺 / 军规 / 复利研究所。

## 二、头像（定稿：禅意圆相）

| 文件 | 用途 |
|------|------|
| `avatar-enso.svg` / `avatar-enso-1024.png` | **定稿**（微信可直接上传 1024×1024）|
| `avatar-monogram.svg` | 备选：榜书大字（近满幅）|
| `avatar-ink.svg` | 备选：深墨圆相 |
| `avatar-note.svg` | 备选：笔记卡+对勾（符号版）|

设计：不闭合圆相（笔意）+ 宋体大字「律」+ 不规则飞白/墨韵 + 做旧朱印（白字「他律」，字不出框）。SVG→PNG 用无头 Chrome 渲染即可（见 `make_cover.py` 同法）。

## 三、公众号封面模板 + 生成

| 文件 | 规格 | 说明 |
|------|------|------|
| `cover-primary.svg` | 900×383（首图，2.35:1）| 左：栏目+两行标题+副题+slogan；右：圆相「律」+ 朱印 |
| `cover-secondary.svg` | 200×200（次图）| 圆相「律」+ 署名 |
| `../make_cover.py` | — | 填充标题（**自动断行**）并渲染 900×383 PNG |

用法：
```powershell
python make_cover.py --series 底层逻辑 --title "Q4第一天，你的时间余额还剩多少" --subtitle "把一年8760小时存进银行" --out workspace/drafts/cover.png
```

## 四、每日自动化（定时跑）

`../daily_run.bat`：激活 venv → `run_daily.py --auto-approve` → 日志写入 `workspace/logs/daily.log`。

用 Windows 任务计划每天 08:30 跑：
```powershell
schtasks /Create /TN "他律手记-每日推文" /SC DAILY /ST 08:30 /TR "\"D:\...\labs\demo-wechat\daily_run.bat\""
```
> 产物为「待审终稿」；你在微信后台**自行发布**。发布后用 `memory_cli.py record` 回填阅读量。

## 五、查重与合规
- 公众号名唯一；个人主体一年可改 2 次。
- 避免违规词与商标近似；头像/封面不含二维码、联系方式、诱导关注元素。
