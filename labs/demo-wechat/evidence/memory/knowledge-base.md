## 《底层逻辑》
### 框架：「年度时间余额表」（第1篇·2026-10-08）
- 全年 8760h = 睡眠 2920h（33%）+ 工作+通勤 2500h（29%）+ 生活杂事 1095h（13%）+ 可自主支配 2245h（25%）
- Q4（84天/2016h）可自主支配 ≈ 492h ≈ 41个清醒日；若每天投入1h×84天=84h≈10.5个工作日的"弹药量"
- 真实时薪 = 年收入 ÷（工作+通勤总小时数），用于消费决策换算
- 核心认知：沉没成本谬误的"年底变体"——用已沉没的9个月给剩余84天判死刑
### 金句（第1篇）
1. "钱花光了可以再赚，时间花光了只会变成'今年又白干了'的叹息。"
2. "放弃不是因为来不及，是因为你把'已经浪费的时间'当成了'未来时间的预言'。但沉没的成本不能预测未来——它只能绑架现在。"
3. "时间管理不是管理时间，是管理注意力——而你最后84天的注意力，比前9个月全部加起来更值钱。"
## 《习惯复利》
### 框架：「弹药复投模型」（第1篇·2026-10-08）
- 四要素：弹药量（总盘）→ 最小行动单位（20分钟/日）→ 复利率（1%法则：1.01^365≈37.78 / 0.99^365≈0.025）→ 终值（20min×365≈122h≈5个工作日净投入）
- 核心机制：复利终值≠线性叠加，而是指数叠加；第N天的投入站在前N-1天积累的台阶上
- 启动摩擦力甜区：20分钟"低到无法拒绝、高到越过摩擦"——不依赖意志力，确保启动率
- 不归零原则：Never miss twice——错过一次是事故，错过两次是破产；连续中断两天后第三天恢复概率断崖式下降
- 间歇性努力陷阱：脉冲式爆发→归零→再爆发→再归零，每次归零清掉前一波成果+透支自我信用
- 弹药复投终值表（每日20min×365≈122h）：英语3650词/写作10.95万字/健身156次/阅读6-7本书
### 金句（第1篇）
1. "间歇性努力的致命伤不在于努力不够，在于每次归零都让上一段白干——你以为在跑步机上跑了很远，其实原地没动一步。"
2. "习惯不是存进去就完事，是每天定投、利滚利、到期取终值——你投的不是20分钟，是20分钟的复利。"
3. "意志力是消耗品，而20分钟是启动摩擦力的甜区——低到不消耗意志力，高到越过静止惯性。"
4. "复利最怕的不是投得少，是中断——同样122小时，连续投入和间歇投入的终值差一个数量级。"
5. "你不需要每天都很猛，你需要每天都不归零——哪怕5分钟也是一颗子弹，保持链条不断就是胜利。"
## 《决策工具箱》
### 框架：「10/10/10 决策法则」（第1篇·2026-10-08）
- 三个时间透镜：10分钟后（情绪层）/ 10个月后（现实层）/ 10年后（价值观层）
- 核心机制：不同时间尺度过滤不同噪音层；10分钟后的情绪噪音最大
- 落地SOP四步：①写决策描述（一句话，越具体越好）→ ②分别回答三个时间点（每个≥3句）→ ③检查"10分钟票"是否绑架全局（是则等48h）→ ④看10年视角是否清晰（不清晰=信息不足，先补信息）
- 快查清单四问：情绪驱动？只算经济账？沉没成本绑架？10年画面清晰？
- 三个决策陷阱：只投10分钟票 / 只算经济账不算时间账 / 沉没成本当未来预言
- 与前文关联：呼应《底层逻辑》第1篇"时间余额"（时间尺度决定可见度）与"沉没成本谬误"
### 金句（第1篇）
1. "你的重大决策之所以反复打脸，不是因为你蠢，是因为你每次都用'10分钟后的自己'替'10年后的自己'签了字。"
2. "10分钟后的你会骗你，10年后的你不会——前者被荷尔蒙绑架，后者只剩下你真正在乎的东西。"
3. "让你焦虑的不是裸辞本身，是你只会用'10分钟后的爽'去衡量一个10年级的决定。"
4. "决策失误不是因为信息不够，是因为你让错误的那个自己投了票——而那个自己，永远是最冲动的那一个。"
5. "好决策的标准不是'结果对了'，是'决策时你清醒了'——10/10/10就是你的清醒开关。"
