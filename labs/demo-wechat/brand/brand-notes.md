# 品牌方案 · 男性向公众号「他律笔记」

> 面向：25-40 岁男性｜方向：男性成长与效率（职场底层逻辑 / 财富习惯 / 认知升级 / 决策工具）
> 调性：**硬核、务实、有体系、可沉淀**（长文 1800-2600 字 / 6-9 分钟）
> 备注：原「他律」在微信已被占用 → 采用后缀方案「**他律笔记**」（更易过审，且强化“体系/沉淀”感）。

## 一、最终定名：**他律笔记**

- **含义**：延续「他律」（不靠意志力、靠系统），「笔记」突出**持续记录、体系化、知识沉淀**。
- **一句话解释**：`他律笔记：不靠意志力，靠系统——把认知写成能复用的笔记。`
- **延展**：栏目用「·系列名」标注（如 `他律笔记 · 底层逻辑`）。

## 二、账号简介（示例）

- 一句话：**「他律笔记：不靠意志力，靠系统——给 25-40 岁男性的认知基建。」**
- 详细版：`只写经得起复盘的硬内容：职场底层逻辑、财富习惯、认知升级、决策工具。用规则与清单替代意志力，把碎片努力变成复利资产。每日一篇体系化长文。`

四个系列即四个专栏：
1. 底层逻辑（职场/商业第一性原理）
2. 习惯复利（财富与自律的长期工程）
3. 决策工具箱（可操作方法与清单）
4. 认知升级（反常识与思维模型）

> 备选（备查）：他驱 / 铁律 / 刻度 / 戒尺 / 军规 / 复利研究所。

## 三、头像设计规范

- **规格**：正方形 1:1，导出 **1024×1024**（微信最小 240×240），PNG/JPG，圆形裁切后主体居中。
- **配色**：深墨蓝底（#0C1220~#1C2A44）+ 琥珀金（#FFB13B~#FF7A00），白字点缀。
- **避坑**：不用真实人脸；细节别太碎；不与知名商标雷同；不含二维码/联系方式。
